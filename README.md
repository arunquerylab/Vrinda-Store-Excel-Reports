# Vrinda-Store-Excel-Reports
Vrinda Store Annual Sales Report 2022

Project Overview

This project analyzes Vrinda Store's annual sales data for 2022 using Microsoft Excel. The goal is to explore sales performance, customer insights, and business trends through an interactive dashboard.

Objectives

- Analyze annual sales performance.
- Identify customer and sales trends.
- Understand key business insights through data visualization.

Tools Used

- Microsoft Excel
- Pivot Tables
- Data Cleaning
- Excel Charts
- Interactive Dashboard

Key Learnings

- Data cleaning and preparation
- Data analysis using Pivot Tables
- Creating charts and visualizations
- Designing an interactive Excel dashboard

Project Credit

This is a guided learning project based on a tutorial by Rishabh Mishra. Created for educational and skill-development purposes.
